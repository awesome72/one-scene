# 디자인 스펙 — 목업에서 추출

> 원본: `docs/design/mockup.html` (브라우저로 열면 7개 화면이 나란히 보인다).
> 이 문서는 프론트엔드 구현(Phase 4, 6, 7)의 기준이다. 목업과 기획안이 다르면 `docs/open-questions.md` 참고.

## 1. 기본 틀
- **모바일 우선**: 화면 기준 390×844 (iPhone 14급). 데스크톱은 같은 단일 열을 가운데 정렬로 시작한다.
- 화면 7개: 홈 → 대화 → 말로 답하기 → 재료 카드 → 계열 짜기 → 초안과 교정 → 보관함

### 글꼴
- **세리프** `'Noto Serif KR', 'Nanum Myeongjo', 'AppleMyungjo', serif` — 코치 질문, 사용자 원문 인용, 초안 본문 (글이 되는 문장)
- **산세리프** `'IBM Plex Sans KR', 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif` — 버튼, 라벨, 안내 문구 (UI)
- 원칙: "사람의 말과 글"은 세리프, "도구의 말"은 산세리프.

## 3. 화면별 구성과 문구

### ① 홈
- 상단: 로고 "한 장면", 우측 "보관함"
- **쓰는 중인 글** 카드: 단계("2단계 단락 구성"), 글 제목("회사를 그만둔 날"), 아크 5블록 표시(장면·사건·의미·현재·여운), 마지막 질문 인용, 버튼 [말로 답하기] [대화 보기]
- **새 글을 여는 질문** 카드: 질문 하나 + [이 질문으로 새 글 시작] [다른 질문] (순환)
  - 질문 목록: "최근, 별일 아닌데 자꾸 생각나는 순간이 있어요?" / "버리지 못하고 아직 갖고 있는 물건이 있어요?" / "누군가 한 말 중에 아직도 그대로 기억나는 문장이 있어요?" / "요즘 누군가에게 말하려다 만 이야기가 있어요?"
- 하단 문구: "한 장면은 글을 대신 쓰지 않습니다. 당신이 한 말만으로 글을 짓습니다."

### ② 대화
- 헤더: 글 제목, 단계, "재료 9" 카운트, 아크 5블록(장면·사건·의미·현재의 나·여운)
- 지난 대화는 흐리게, **지금 질문**은 크게 세리프로. 질문 안에서 사용자 말 인용(‘그 자리에서 바로’)을 강조
- 사용자 답 안의 반복·핵심 구절도 강조 표시
- 하단: [누르고 말하기] (주 버튼) / [답 쓰기] / "이 질문은 넘어가기" (상시 노출)

### ③ 말로 답하기
- 상단에 지금 질문 다시 표시
- 녹음 중: 실시간 받아쓰기 + "듣고 있어요 0:21" + [다 말했어요]
- 확인 단계: "들은 내용을 확인해 주세요" — 변환된 텍스트, **반복된 말 강조**(창밖), "잘못 들은 곳은 눌러서 바로 고칠 수 있어요"
- 반복 알림: "‘창밖’이 이 글에서 세 번째로 나왔어요. 반복된 말로 기록해 둘게요."
- 버튼: [다시 말하기] [이대로 보내기] — **자동 전송 없음**

### ④ 재료 카드
- "2단계 단락 구성을 마칠 수 있어요" / "모두 당신이 한 말입니다" / "쓰지 않을 재료는 눌러서 빼 둘 수 있어요."
- 블록별 카드(라벨·상태·원문): 상태는 "재료 n개" 또는 "빼 둠" (토글 → `materials.excluded`)
- 반복된 말 ("창밖 3회"), 열린 틈 ("그 말을 처음 들은 날")
- 버튼: [조금 더 이야기하기] [계열 짜기로 넘어가기]

### ⑤ 계열 짜기
- "모은 장면을 어떤 순서로 놓을까요?" + 반복 이미지 안내 ("‘창밖’이 첫 장면과 마지막 장면에 모두 있어요.")
- 패턴 4개 선택 버튼: 직선형(장면에서 여운까지 차례대로) / 회귀형(결정적 장면에서 과거로 갔다 돌아오기) / 액자형(지금의 장면 안에 과거를 넣기) / 교차형(과거와 현재를 번갈아)
- 선택 시 **단락 개요** 갱신: 번호·블록·재료 요약·예상 분량, 합계("6단락, 약 2,800자")
- 패턴별 블록 순서 (목업 데이터):
  - 직선형: 장면 → 사건과 배경 → 의미 → 현재의 나 → 여운
  - 회귀형: 장면 → 사건과 배경 → 장면으로 돌아오기 → 의미 → 현재의 나 → 여운
  - 액자형: 지금의 장면 → 장면 → 사건과 배경 → 의미 → 지금으로 돌아오기 → 여운
  - 교차형: 지금의 장면 → 장면 → 현재의 나 → 사건과 배경 → 의미 → 여운
- 버튼: [이 순서로 초안 만들기] + "초안을 만든 뒤에도 순서는 바꿀 수 있어요"

### ⑥ 초안과 교정
- "붉은 표시를 누르면 질문이 열려요" + 표시 개수("4곳")
- 초안 본문(세리프)에 번호 붙은 붉은 표시. 빈칸은 "‸ 비워 둔 자리"
- 표시 종류와 설명(why) 문구:
  1. 상투 표현 — "감정을 대신하는 익숙한 표현이에요."
  2. 감정 명명과 과장 — "감정의 이름과 강조하는 말이 함께 있어요."
  3. 재료가 없는 자리 — "대화에 없던 내용이라 지어내지 않고 비워 두었어요."
  4. 깨달음 상투 — "깨달음을 말로 정리하는 익숙한 표현이에요."
- 하단 시트: "n / 4", 종류, why, 교정 질문 하나, [그대로 두기] [말로 답하기]
- 안내: "모든 문장은 대화에서 나온 당신의 말에 연결되어 있어요."

### ⑦ 보관함
- "완성한 글 1편" / 글 카드: 완성일, "6단락, 2,800자", 제목, 첫 문장
- 태그: 시기 · 인물 · 장소 · 핵심 사물
- **다음 글감**: "대화에서 나왔지만 아직 쓰지 않은 장면이에요" — 질문 형태 + 출처("‘회사를 그만둔 날’에서 나온 질문"). 누르면 새 세션 시작

## 4. 구현 메모
- 목업은 데모 데이터로 "회사를 그만둔 날" 한 편을 일관되게 쓴다 → `backend/tests/golden/`과 프론트 스토리/시드 데이터로 재사용 가능
- 목업의 `{{...}}` 자리는 서버 응답으로 채울 값이다 (패턴 정의, 재료 카드 블록, 교정 표시 목록)
