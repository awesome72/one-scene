# 서비스 기획안: 「한 장면」

> 묻는 AI, 쓰는 사람. 기억 속 한 장면에서 시작하는 대화형 글쓰기 서비스

---

## 1. 한 줄 정의

말로 답하면 AI가 한 번에 하나씩 질문하며 기억 속 장면을 끌어내고, 그 재료만으로 "장면에서 시작해 여운으로 끝나는" 에세이를 완성하게 돕는 대화형 글쓰기 서비스.

---

## 2. 문제 정의

| 문제 | 현재 상황 | 결과 |
|---|---|---|
| 무엇을 쓸지 모른다 | 빈 화면 앞에서 시작을 못 함 | 쓰고 싶은 마음만 있고 글이 안 나옴 |
| AI가 대신 써준다 | 주제만 넣으면 매끈한 글이 나옴 | 누구나 쓸 수 있는 글, 내 이야기가 아님 |
| 감정을 설명한다 | "슬펐다, 행복했다"로 채움 | 독자에게 전달되지 않음 |
| 말은 잘하는데 글은 못 쓴다 | 말로는 생생한데 글로 옮기면 딱딱해짐 | 가장 좋은 재료가 사라짐 |

**핵심 통찰:** AI 시대에 부족한 것은 문장이 아니라 **질문**이다. 문장 생성은 흔해졌지만, 한 사람의 기억에서 그 사람만 쓸 수 있는 장면을 꺼내는 질문은 여전히 드물다.

---

## 3. 타깃 사용자

### 1차 타깃
- **쓰고 싶은데 시작을 못 하는 일반인** (30~60대): 블로그, 브런치, 뉴스레터, 회고록을 꿈꾸지만 습관이 안 잡힌 사람
- **말은 잘하는데 글이 어려운 사람**: 강연가, 영업인, 상담가, 종교인, 경력이 긴 전문가

### 2차 타깃
- 자서전·가족사를 남기고 싶은 시니어 (구술 중심)
- 글쓰기 수업 강사 (수강생 과제 도구)
- 기업의 창업자 스토리·사내 회고 콘텐츠

### 페르소나
| 이름 | 상황 | 원하는 것 | 막히는 지점 |
|---|---|---|---|
| 지현 (38, 직장인) | 퇴사 후 경험을 브런치에 쓰고 싶음 | 진짜 내 이야기 | 쓰면 다 뻔한 퇴사 후기가 됨 |
| 영수 (63, 은퇴) | 자녀에게 남길 이야기 | 말로 하면 술술 나옴 | 타자가 느리고 글로 옮기면 어색함 |
| 수아 (29, 마케터) | 뉴스레터 주 1회 발행 | 꾸준한 글감 | 매주 무엇을 쓸지 고갈 |

## 4. 핵심 가치와 원칙

### 서비스 약속 3가지
1. **당신의 기억만 씁니다.** AI는 지어내지 않습니다. 빈 곳은 질문으로 남깁니다.
2. **한 번에 하나만 묻습니다.** 질문 폭탄은 없습니다.
3. **결정은 당신이 합니다.** 주제, 순서, 의미는 당신이 정합니다.

### 철칙 (스킬 문서 1장과 동일)
1. 한 번에 질문 하나
2. 추상이 아니라 장면을 묻는다
3. 요약하지 않고, 조언하지 않고, 파고든다
4. 준 기억만 쓴다
5. 상투와 과장 없이, 감정은 장면으로

## 5. 차별점

| 비교 항목 | 일반 AI 글쓰기 도구 | 일반 글쓰기 강좌 | **한 장면** |
|---|---|---|---|
| 누가 쓰나 | AI | 나 혼자 | 나 (AI는 질문) |
| 글감 발굴 | 주제를 입력해야 함 | 과제로 주어짐 | 대화로 기억에서 발굴 |
| 진정성 | 그럴듯한 지어냄 | 높음 | 높음 + 출처 추적 |
| 입력 방식 | 타이핑 | 타이핑 | 말과 타이핑 모두 |
| 피드백 | 즉시 다시 써줌 | 주 1회 첨삭 | 문장 단위 질문형 교정 |
| 지속성 | 일회성 | 수강 기간 | 태그·열린 틈으로 다음 글감 이어짐 |

## 6. 사용자 여정

```
[시작]  "오늘은 무엇을 쓸까요?" or "최근 이상하게 생각나는 순간이 있어요?"
   │    (마이크 버튼 하나. 말해도 되고 써도 된다)
   ▼
[1단계 주제 설정]  장면 → 사물 → 직전 → 왜 이 장면?
   │    ▶ 재료 카드 ① : 한 문장 주제 / 오프닝 장면 / 목표 길이
   ▼
[2단계 단락 구성]  아크 5블록(장면·사건·의미·현재·여운) 채우기
   │    ▶ 재료 카드 ② : 블록별 재료 지도
   ▼
[3단계 계열 짜기]  시간 구조, 연결 고리, 생략, 반복 이미지
   │    ▶ 단락 개요 : 번호 + 재료 원문 + 예상 분량
   ▼
[4단계 태그와 교정]  초안 조립 → 7가지 교정 점검 → 소리 내어 읽기 → 태그
   │    ▶ 완성 글 + 출처 표시 + 태그 + 열린 틈
   ▼
[아카이브]  열린 틈이 다음 글감 추천으로 돌아옴
```

**예상 소요 시간 (보통 글 2,000~3,000자 기준)**
| 단계 | 대화 턴 수 | 시간 |
|---|---|---|
| 1. 주제 설정 | 8~12턴 | 10~15분 |
| 2. 단락 구성 | 12~20턴 | 15~25분 |
| 3. 계열 짜기 | 5~8턴 | 5~10분 |
| 4. 태그와 교정 | 8~15턴 | 10~20분 |
| 합계 | 33~55턴 | 40~70분 (여러 세션으로 나눠도 됨) |

## 7. 기능 명세

### MVP (v0.1, 6주)
| # | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F1 | 대화형 질문 엔진 | 스킬 문서 기반, 단계별 시스템 프롬프트 | 필수 |
| F2 | 음성 입력 | 마이크 버튼 → STT → 텍스트 확인 후 전송 | 필수 |
| F3 | 재료 추출 | 매 턴 사용자 발화에서 재료(장면·사물·대사 등)를 원문 그대로 저장 | 필수 |
| F4 | 단계 진행 표시 | 상단 4단계 진행 바 + 아크 5블록 채움 상태 | 필수 |
| F5 | 재료 카드 | 단계 마감 시 원문 재료 모음 표시, 다음 단계 이동 버튼 | 필수 |
| F6 | 초안 조립 | 요청 시 단락 개요대로 조립, `[빈칸]` 표시, 단락별 출처 | 필수 |
| F7 | 교정 점검 | 상투어·과장어·감정 명명 하이라이트 (규칙 기반 + LLM) | 필수 |
| F8 | 글 보관함 | 완성 글 목록, 태그, 열린 틈 | 필수 |

## 8. 화면 구성

### 메인 대화 화면
```
┌──────────────────────────────────────────────┐
│  ● 주제 설정 ─ ○ 단락 구성 ─ ○ 계열 ─ ○ 교정     │  ← 단계 진행
├────────────────────────────┬─────────────────┤
│                            │  서사 아크        │
│  코치: 그만두기로 마음먹은   │  ■ 장면  (2)     │
│  그 순간, 어디에 있었어요?   │  □ 사건  (0)     │
│                            │  □ 의미  (0)     │
│  나: 회의실이었어요...       │  □ 현재  (0)     │
│                            │  □ 여운  (0)     │
│  코치: "또 같은 얘기"라고    │                 │
│  하셨어요...                │  반복된 말       │
│                            │  창밖 ×3         │
│                            │                 │
├────────────────────────────┴─────────────────┤
│        [ 🎙 길게 눌러 말하기 ]   [ 입력창 ]       │
└──────────────────────────────────────────────┘
```
- 질문은 한 화면에 하나만 크게. 이전 대화는 위로 스크롤.
- 오른쪽 패널(모바일은 하단 시트)은 재료가 쌓이는 모습을 보여줘 동기를 준다.

### 초안·교정 화면
- 왼쪽: 초안 (하이라이트 — 노랑: 상투어, 주황: 감정 명명, 회색 점선: `[빈칸]`)
- 오른쪽: 하이라이트를 누르면 해당 문장을 인용한 교정 질문 하나
- 단락 옆 작은 아이콘을 누르면 출처 재료(대화 원문) 표시

## 9. AI 설계

### 프롬프트 구조
```
[시스템]  SKILL.md 공통 원칙 (철칙, 응답 형식, 파고들기 기법, 금지 사항)
        + 현재 단계 모듈 (해당 단계 섹션만)
        + 세션 상태 요약 (YAML)
[대화]   최근 N턴 원문
```

### 에이전트 역할 분리
| 역할 | 하는 일 | 모델 |
|---|---|---|
| 질문자 | 다음 질문 하나 생성 | 고품질 모델 (Sonnet급) |
| 재료 추출기 | 사용자 발화 → 재료 JSON (원문 보존) | 경량 모델 (Haiku급) |
| 질문 검수기 | 질문 품질 5개 기준 체크, 실패 시 재생성 | 경량 모델 |
| 초안 조립기 | 개요 + 재료 → 초안, 출처 ID 필수 | 고품질 모델 |
| 진실성 검사기 | 초안 문장마다 출처 재료 존재 여부 확인 | 고품질 모델 |
| 상투어 린터 | 사전 기반 규칙 검사 | 규칙 엔진 (모델 없음) |

## 10. 성공 지표

### 질문 품질 (자동 측정)
| 지표 | 목표 |
|---|---|
| 응답당 질문 수 = 1 비율 | 98% 이상 |
| 사용자 직전 발화 인용률 | 85% 이상 |
| 질문 검수 1차 통과율 | 80% 이상 |

### 글 품질
| 지표 | 목표 |
|---|---|
| 초안 문장의 출처 연결률 | 100% (출처 없는 문장 0) |
| 완성 글 내 상투어 사전 적중 | 1,000자당 0.5개 이하 |
| 첫 문장이 장면으로 시작하는 비율 | 90% 이상 |

### 사용자 행동
| 지표 | 목표 (출시 3개월) |
|---|---|
| 첫 세션 → 1단계 완료율 | 60% |
| 1단계 → 글 완성률 | 35% |
| 월 2편 이상 완성 사용자 비율 | 20% |
| 음성 입력 사용 비율 | 40% |
| "내 이야기 같다" 만족도 (5점) | 4.3 이상 |

## 14. 첫 실험 (이번 주에 바로)

1. `SKILL.md`를 Claude의 프로젝트 지침이나 스킬로 등록한다.
2. 본인이 직접 글 한 편을 4단계로 완주해본다.
3. 질문 중 "어느 대답 뒤에 붙여도 되는 질문"이 몇 개였는지 센다. 이것이 첫 개선 지표다.
4. 지인 3명에게 같은 방식으로 시켜보고, 완성 글을 "내 이야기 같다" 5점 척도로 묻는다.
