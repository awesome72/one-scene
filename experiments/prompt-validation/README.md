# Step 1. 프롬프트 검증 실험

> 기획안 13~14장의 "1~2주 프롬프트 검증". 코드를 쓰기 전에 SKILL.md만으로 **질문만으로 글이 나오는가**를 확인한다.

## 실험 방법

### 1) 스킬 실행 환경 (둘 중 하나)
- **Claude Code (이 폴더)**: SKILL.md가 `.claude/skills/scene-essay-coach/`에 있으므로 프로젝트 스킬로 바로 인식된다. 새 세션에서 "회사 그만둔 얘기를 쓰고 싶어요"처럼 말하면 스킬이 동작한다.
- **claude.ai**: 프로젝트를 만들고 SKILL.md 내용을 프로젝트 지침에 붙여 넣는다. 음성 입력(모바일 앱)을 함께 시험할 수 있어 구술 모드 검증에 더 적합하다.

### 2) 진행
1. 본인이 글 한 편을 4단계로 끝까지 쓴다 (40~70분, 여러 번 나눠도 됨).
2. 대화 전체를 `logs/YYYYMMDD-이름-주제.md`로 저장한다.
3. 아래 채점표대로 코치 응답을 하나씩 표시한다.
4. 지인 3명에게 같은 방식으로 쓰게 하고, 완성 글에 "내 이야기 같다"를 5점 척도로 묻는다.
5. 목표: 대화 20건.

## 채점 기준 (코치 응답 1개마다)
| 코드 | 의미 | 근거 |
|---|---|---|
| `G` | **어느 대답 뒤에 붙여도 되는 질문** (핵심 지표) | 기획안 14장 |
| `Q2` | 질문이 2개 이상 | 철칙 1 |
| `AB` | 장면이 아니라 추상·감정을 물음 | 철칙 2 |
| `SUM` | 요약·조언·의미 부여 | 철칙 3 |
| `EMP` | 공감 상투어 ("힘드셨겠어요") | 3장 |
| `LEAD` | 유도 질문 | 3장 |

초안에 대해서는: 지어낸 디테일 개수(`FAB`), `[빈칸]` 개수, 첫 문장이 장면인지, 마지막 문장이 교훈 선언인지.

## 기록
- 세션별 집계는 `scores.csv`에 한 줄씩 추가한다.
- 목표치(기획안 10장): 질문 1개 비율 98% 이상, 직전 발화 이어받기 85% 이상, 지어낸 문장 0, "내 이야기 같다" 4.3 이상.
