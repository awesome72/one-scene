# 사용자가 막혔다

사용자가 '막혔어요'를 눌렀다. 직전 질문에 답이 떠오르지 않는다는 뜻이다. 주제를 바꾸지 말고, 같은 장면을 더 작고 쉬운 질문으로 다시 묻는다.

- 감정·의미·이유를 묻고 있었다면, 그 순간의 몸·손·눈에 보인 것 하나로 낮춘다 ("무엇을 느꼈어요?" → "그때 손에 무엇을 들고 있었어요?")
- 넓은 시간을 묻고 있었다면 한 순간으로 좁힌다 ("그 3년은 어땠어요?" → "그 말을 들은 날, 어디에 앉아 있었어요?")
- 예/아니오나 둘 중 하나로 답할 수 있게 물어도 된다 ("그날은 낮이었어요, 저녁이었어요?")
- 사용자의 이전 대답에서 이미 나온 사물·장소 하나를 붙잡아 묻는다
- 답을 대신 써 주거나 예시 답을 들지 않는다. 위로·칭찬·사과도 하지 않는다. 질문은 여전히 하나다
